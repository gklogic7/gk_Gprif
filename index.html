About Gprif

Gprif is a free web tool that turns sprite sheets into animated GIFs. Useful for video game creators and animators.

Upload your sprite sheet image, then use the controls to set row / column count, frame duration, and image offset margins.

The tool then converts your sprite sheet into a GIF file, right in your browser. Nothing is uploaded to a server.

Free and open source (MIT license), with no paywalls or premium options. Use it for personal or commercial projects.

Built with vanilla JavaScript, HTML5 canvas, and CSS. GIF creation uses the gif.js library by Johan Nordberg. Gprif is based on the open source Sprite Sheet to GIF project by Alan (collidingScopes).
